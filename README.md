# CML – College Club Website
This website is built using **HTML**, **CSS**, and **JavaScript** only — with no external frameworks — to keep it lightweight, fast, and accessible.

---

## 📌 Features

- ✨ Clean, responsive design
- 📰 About Us & Events section
- 📸 Gallery / Media highlights
- 🧠 Information about club activities and teams
- 📬 Contact form (optional)
- 🔐 No frameworks or back-end — pure front-end site
